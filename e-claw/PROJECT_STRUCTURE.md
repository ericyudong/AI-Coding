# E-Claw 企业级AI智能体运行平台

## 项目概述

**E-Claw** 是基于OpenClaw架构设计的企业级AI智能体运行平台，采用三层融合架构，支持多租户隔离、断点续跑、RAG检索等核心能力。

## 技术栈

- **后端**: Python 3.11+ / FastAPI
- **数据库**: PostgreSQL + Redis
- **前端**: Vue 3 + TypeScript + Element Plus
- **AI引擎**: LangChain + 本地LLM
- **通信**: WebSocket + RESTful API
- **部署**: Docker + Kubernetes

## 核心功能模块

### 1. 多租户隔离
- 租户创建、禁用、删除
- 租户资源配额分配
- 租户数据完全隔离

### 2. 任务管理
- 多模态任务提交（文档、图片、音频、视频）
- 任务优先级调度
- 任务状态跟踪
- 断点续跑机制

### 3. 知识库管理
- 个人知识库
- 部门共享知识库
- RAG检索
- 文档审核流程

### 4. 权限控制
- RBAC模型
- 角色：员工、部门管理员、超级管理员、运维
- 部门级、资源级权限控制

### 5. 资源配额
- Token计量
- 部门配额分配
- 个人配额管理
- 使用统计报表

### 6. 审计日志
- 全链路操作记录
- 多维度查询
- 日志导出

## API接口设计

### 认证接口
- `POST /api/v1/auth/login` - 用户登录
- `POST /api/v1/auth/logout` - 用户登出
- `GET /api/v1/auth/me` - 获取当前用户信息

### 任务接口
- `POST /api/v1/tasks` - 提交任务
- `GET /api/v1/tasks` - 获取任务列表
- `GET /api/v1/tasks/{id}` - 获取任务详情
- `DELETE /api/v1/tasks/{id}` - 取消任务
- `POST /api/v1/tasks/{id}/resume` - 恢复任务

### 知识库接口
- `GET /api/v1/knowledge` - 获取知识库列表
- `POST /api/v1/knowledge` - 添加文档
- `DELETE /api/v1/knowledge/{id}` - 删除文档
- `GET /api/v1/knowledge/search` - 搜索知识库

### 管理员接口
- `GET /api/v1/admin/tenants` - 获取租户列表
- `POST /api/v1/admin/tenants` - 创建租户
- `GET /api/v1/admin/users` - 获取用户列表
- `GET /api/v1/admin/audit` - 查询审计日志
