产品简介

益慧科技 AI+ · 法务是一套面向企业法务与合规团队的智能化工作平台，整合法律检索、合同管理、诉讼辅助与专业问答等能力， 帮助用户提升法务工作效率与决策质量。

平台采用 AI 大模型与知识库相结合的技术路线，在保障数据安全的前提下提供智能分析与辅助决策。

四大核心模块

检索AI

  • 综合分析
  • 法规查询
  • 类案检索
  • 行政处罚检索

合同AI

  • 合同台账管理
  • 合同导入与检索
  • 版本对比
  • 合同审核与起草

诉讼AI

  • 诉讼策略分析
  • 诉讼文书辅助
  • 要素式文书生成
  • 类案与法规支撑

问答AI

  • 劳动法专业问答
  • 金融合规咨询
  • 企业出海合规
  • 多轮对话交互

快速上手

  1. 使用企业账号登录系统，进入首页后可浏览四大 AI 模块入口。
  2. 在首页搜索框输入法规或案例关键词，或通过「益慧AI+」进入智能检索。
  3. 点击「合同AI」进入合同管理系统，支持导入、台账、检索与版本对比。
  4. 在「问答AI」中选择劳动法、金融合规或企业出海等专题进行专业咨询。
  5. 通过顶部「帮助」菜单可随时查看本手册或联系益慧获取支持。

常见问题

Q：AI 功能需要额外配置吗？

管理员在服务端配置大模型 API 后即可启用完整 AI 能力；未配置时部分功能以演示模式运行。

Q：合同数据存储在哪里？

合同数据存储在企业部署的服务端数据库中，可按企业安全策略进行备份与权限管理。

Q：如何获取技术支持？

请通过系统内「帮助 → 联系益慧」获取官方联系方式。
