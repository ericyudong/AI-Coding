## 1. 产品概述

### 1.1 定位

面向企业内部法务与业务协同场景，提供「工作台 + 四大 AI 能力域」：

1. **知识资产 AI**：企业知识多轮问答  
2. **合同 AI**：合同导入解析、台账、检索、版本对比、详情问答与标签摘要（含标签体系字典）  
3. **履约 AI**：履约计划、供应商/客户、调整审批（证据附件）、站内+邮件预警、ERP 订单同步  
4. **商业模式 AI**：**入口预留**，页面提示功能开发中  

### 1.2 设计原则

- **人机协同**：AI 提取/推荐，关键业务节点需人工确认（履约生效、摘要锁定、标签变更审计、调整审批）  
- **权限与隔离**：按角色开放功能；合同数据按「本人 + 部门」或跨部门全量可见  
- **可追溯**：标签、摘要、状态变更写入操作日志；关键行为可埋点；预警邮件有发送状态  
- **可配置扩展**：SMTP、对象存储目录、标签字典、ERP 导入模式均可配置或后台维护  

### 1.3 目标用户

| 角色 | 典型诉求 |
|------|----------|
| 系统管理员 | 用户/角色/标签体系配置、全量数据、邮件与同步运维 |
| 法务人员 | 合同导入、标签、检索、履约审批、知识问答 |
| 业务 / 销售 / 采购 | 查合同、看履约待办、客户或供应商、订单同步 |
| 财务 / 管理 | 履约全量视角、调整审批、导出 |

## 4. 功能设计详述

### 4.1 工作台

**目标**：一站式入口与轻量问答。

**能力**：

- 顶部 AI 对话框（多轮会话）  
- 四模块卡片跳转  
- 按角色展示推荐问题  

**页面**：`/` · `HomeView.vue`

---

### 4.2 知识资产 AI

**目标**：基于企业知识的多轮问答。

**能力**：

- 对话式问答  
- 与合同库能力联动入口（卡片文案）  

**页面**：`/knowledge` · `KnowledgeView.vue`  
**接口**：`POST /api/v1/chat`

---

### 4.3 合同 AI

#### 4.3.1 合同导入（异步）

**用户故事**：法务上传合同文件后，系统后台 OCR/解析并抽取字段，用户核对后入库或关联为新版本。

**流程**：

```
上传（单文件 / 批量）
  → 入队（queued）
  → 解析处理（processing：OCR/正文）
  → 结构化提取（completed / failed）
  → 失败可重试
  → 用户确认入库（新建合同 / 关联已有合同为新版本）
```

**约束**：

| 项 | 值 |
|----|-----|
| 单文件大小 | ≤ 100MB |
| 批量文件数 | ≤ 50 |
| 支持格式 | PDF、DOC、DOCX、XLSX、JPG、JPEG、PNG |
| 权限 | 系统管理员、法务 |

**界面要点**：

- 拖拽/点击上传  
- 进度步骤与解析日志表  
- 批量任务全量轮询至完成  
- 关联合同建议  

**页面**：`/cms/import`

#### 4.3.2 合同台账

**能力**：统计卡片、列表/卡片视图、状态筛选、新建、批量改状态、删除、CSV 导出、进入详情。

**页面**：`/cms/ledger`

#### 4.3.3 合同详情

**信息结构（Tabs）**：

| Tab | 内容 |
|-----|------|
| 基本信息 | 状态、类型、金额、甲乙方、日期、负责人、风险；智能标签（L1/L2 + tags） |
| AI 摘要 | 简短 / 详细 / 风险 / 时间线；支持人工修改并锁定 |
| 操作日志 | 标签、摘要、状态等变更审计 |
| 版本历史 | 版本列表与对比入口 |
| 原文预览 | 提取正文 |

**侧栏**：合同级 AI 问答（RAG），展示回答与引用置信度提示。

**业务规则**：

- 人工保存摘要后 `summary_locked = true`，后续 AI 不再覆盖已锁定摘要  
- 标签编辑：一级/二级须落在**标签体系字典**内；三级可为建议词或多值自定义  
- 标签与摘要编辑受功能权限控制；状态变更写入审计日志  

**页面**：`/cms/contracts/:id`  
**字典接口**：`GET /cms/tags/taxonomy`

#### 4.3.4 合同检索

**检索模式**：混合、语义、关键词、字段、正则、自然语言。

**能力**：建议词、标签云、结果高亮与跳转详情。

**页面**：`/cms/search`

#### 4.3.5 版本对比

选择同一合同两个版本，输出差异摘要与变更项、风险提示。

**页面**：`/cms/compare`

---

### 4.4 履约 AI

#### 4.4.1 履约总览

- 指标：履约计划数、已生效、待确认、即将到期、已违约  
- 站内预警列表（含**邮件发送状态**；可标记已读）  
- 我的待办（节点、到期、剩余天数）  

**页面**：`/performance`

#### 4.4.2 履约助手

**主流程**：

```
输入合同 ID → AI 提取履约时间线（草稿）
  → 人工确认计划生效
  → 节点：分配责任人 / 标记完成
  → 申请调整（原因 + 证据说明和/或证据文件 + 可选新到期日）
  → 法务/管理/财务审批（通过则落库日期/责任人；驳回保留原状）
```

**规则**：

- 逾期无宽限期，超期自动标记违约  
- 预警窗口默认 **7 天**（即将到期）  
- 证据支持**文本说明**与**文件附件**（本地对象存储）  

**页面**：`/performance/assistant`

#### 4.4.3 站内 + 邮件预警

| 能力 | 说明 |
|------|------|
| 站内预警 | 责任人可见；支持已读 |
| 邮件渠道 | 通道配置含 `email`；写入 `email_status`：pending / sent / skipped / failed |
| 定时任务 | 后台调度（默认约 15 分钟）刷新预警并尝试发信 |
| 手动派发 | `POST /performance/alerts/dispatch`；助手页「派发邮件」 |
| SMTP | 默认关闭；关闭时状态为 `skipped`，开启后真实发送 |

**配置项**：`SMTP_ENABLED`、`SMTP_HOST/PORT/USER/PASSWORD/FROM`、`PERFORMANCE_ALERT_INTERVAL_SECONDS`、`PERFORMANCE_ALERT_CHANNELS`

#### 4.4.4 调整证据对象存储

| 项 | 说明 |
|----|------|
| 存储位置 | `data/objects/performance_evidence/{user_id}/{uuid}.ext` |
| 上传 | `POST /performance/nodes/{id}/evidence` |
| 绑定 | 调整申请字段：`evidence_path`、`evidence_filename`、`evidence_note` |
| 下载 | `GET /performance/adjustments/{id}/evidence`（需登录鉴权） |
| 格式 | pdf / png / jpg / jpeg / doc / docx / xlsx |
| 大小 | 默认 ≤ 50MB（`PERFORMANCE_EVIDENCE_MAX_BYTES`） |

#### 4.4.5 供应商中心 / 客户中心

- 供应商：合作金额、合同数、延期、风险等级等  
- 客户：独立/合并视图、关联公司关系维护；订单统计可随 ERP 导入回写  

**页面**：`/performance/suppliers` · `/performance/customers`

#### 4.4.6 ERP / 订单同步

**目标**：将外部订单（CSV）导入并与客户/合同关联，支撑客户画像中的订单维度。

**流程**：

```
上传 CSV → 按 external_id/order_no upsert
  → 按合同编号 / 客户名称自动关联
  → 未匹配标 pending，支持人工关联
  → 回写客户 order_count / total_sales / total_qty
```

**CSV 表头（兼容中英文）**：`order_no`、`customer_name`、`contract_code`、`product_name`、`qty`、`unit_price`、`amount`、`order_date`、`status` 等。

| 项 | 说明 |
|----|------|
| 默认模式 | `ERP_SYNC_MODE=manual_import` |
| API 预留 | `api` 模式需配置 `ERP_API_BASE_URL`（适配器待对接） |
| 页面 | `/performance/orders` |
| 样例文件 | `doc/samples/erp_orders_sample.csv` |
| 主要接口 | `POST /orders/import`、`GET /orders`、`PATCH /orders/{id}/link`、`GET /orders/sync-jobs` |

## 5. 关键用户旅程

### 5.1 法务导入并归档合同

1. 登录（法务/管理员）→ 合同导入  
2. 上传 PDF/Word/图片 → 等待异步解析  
3. 核对抽取字段 → 确认新建或关联版本  
4. 台账中查看 → 详情按标签体系补 L1/L2/三级标签、改摘要（锁定）→ 可选检索验证  

### 5.2 业务人员查合同与履约

1. 登录 → 工作台或合同检索  
2. 仅见本人/本部门合同  
3. 履约总览查看待办与预警（含邮件状态）→ 履约助手跟进节点  

### 5.3 履约调整审批（含证据附件）

1. 责任人在助手页申请调整：填写原因、证据说明，可选上传证据文件  
2. 法务/财务/管理在待审批列表查看说明/下载附件后通过或驳回  
3. 通过后节点到期日/责任人更新；预警按新日期刷新并可邮件通知  

### 5.4 管理员维护标签与订单

1. 系统管理 → 标签体系：维护 L1/L2/L3 字典  
2. 履约 AI → ERP 订单同步：导入 CSV，处理待关联订单

### 6.2 关键配置项（产品相关）

- 登录鉴权（JWT）  
- 接口级功能权限校验
