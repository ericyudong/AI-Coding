# HR 系统招聘模块架构设计

## 1. 概述

### 1.1 模块定位

招聘模块是 HR 系统的核心业务子系统，负责从职位需求发起到候选人入职的全生命周期管理。该模块以**招聘流程引擎**为核心，集成人才库、面试评估、Offer 管理和数据分析能力，支撑企业高效、合规地完成人才获取。

### 1.2 设计目标

- **流程可配置**：支持不同职位类型自定义招聘流程（校招/社招/猎头/内推）
- **数据全链路**：候选人从触达到入职的完整数据闭环，无信息断层
- **协作高效**：HR、面试官、用人部门、候选人多方协同，状态实时同步
- **合规可审计**：所有操作留痕，满足劳动法规和企业内控要求
- **智能辅助**：AI 简历解析、智能推荐、自动化通知，降低人工重复劳动

## 2. 核心功能矩阵

### 2.1 职位管理

| 功能 | 描述 |
| :--- | :--- |
| 职位需求申请 | 用人部门提交 HC 申请，关联编制预算，多级审批流 |
| 职位发布 | 一键多渠道发布（官网/招聘平台/内推/社交媒体），统一 JD 模板 |
| 职位看板 | 按状态（草稿/审批中/招聘中/暂停/关闭）分类管理，支持批量操作 |
| 职位版本控制 | JD 修改保留历史版本，变更记录可追溯 |
| 编制联动 | 与组织架构和人力编制模块实时校验，超编自动拦截 |

### 2.2 候选人管理

| 功能 | 描述 |
| :--- | :--- |
| 多渠道简历收集 | 招聘平台 API 对接、邮箱解析、内推链接、官网投递、猎头导入 |
| AI 简历解析 | 自动提取姓名/学历/工作经历/技能标签，结构化存储 |
| 人才库 | 候选人长期沉淀，支持多维度检索（技能/经验/地域/薪资期望） |
| 候选人画像 | 聚合应聘记录、面试评价、沟通历史、标签，360° 视图 |
| 去重与合并 | 基于手机号/邮箱/身份证智能去重，多来源记录自动合并 |
| GDPR/隐私合规 | 候选人授权管理、数据保留策略、匿名化/删除能力 |

### 2.3 招聘流程引擎

| 功能 | 描述 |
| :--- | :--- |
| 可视化流程编排 | 拖拽式配置招聘阶段（筛选→笔试→一面→二面→HR面→Offer→入职） |
| 阶段推进规则 | 自动/手动推进，支持条件分支（如：笔试成绩 < 60 自动淘汰） |
| 审批流集成 | Offer 审批、特殊录用审批、编制外审批等嵌入式工作流 |
| SLA 监控 | 各阶段停留时长预警，超时自动提醒负责人 |
| 批量操作 | 批量推进/淘汰/转岗/标记，提升大批量招聘效率 |
| 流程模板 | 预设校招/社招/高管/实习等模板，新建职位一键套用 |

### 2.4 面试管理

| 功能 | 描述 |
| :--- | :--- |
| 面试安排 | 日历视图排期，自动检测面试官空闲时段，支持群面/交叉面 |
| 面试通知 | 短信/邮件/企微/钉钉多渠道自动通知候选人和面试官 |
| 在线面试集成 | 对接腾讯会议/Zoom/飞书，自动生成会议链接并嵌入系统 |
| 面试评价表 | 结构化评分维度（专业能力/沟通/文化匹配），支持自定义模板 |
| 评价汇总 | 多轮面试评价自动聚合，对比视图辅助决策 |
| 面试签到 | 候选人扫码签到，实际到场率统计 |
| AI 面试助手 | 面试问题推荐、实时记录转写、关键信息自动提取 |

### 2.5 Offer 管理

| 功能 | 描述 |
| :--- | :--- |
| Offer 生成 | 基于薪酬体系自动计算薪资方案，支持多套方案对比 |
| 电子 Offer | 在线签署，候选人移动端确认，法律效力等同纸质 |
| 审批流程 | 多级审批（HR→部门负责人→VP→CEO），金额分级授权 |
| Offer 有效期 | 到期自动提醒，过期自动作废或延期审批 |
| 背景调查 | 集成三方背调服务，报告自动关联候选人档案 |
| 入职衔接 | Offer 接受后自动触发入职流程（设备申请/账号开通/导师分配） |

### 2.6 内推管理

| 功能 | 描述 |
| :--- | :--- |
| 内推门户 | 员工可查看热招职位，一键生成专属内推链接/海报 |
| 内推奖励 | 奖金规则配置（按职位级别/入职时间阶梯），发放跟踪 |
| 进度透明 | 推荐人实时查看候选人状态，淘汰自动通知原因 |
| 防作弊 | 同候选人多推荐人去重规则，入职后奖励才生效 |

### 2.7 招聘数据分析

| 功能 | 描述 |
| :--- | :--- |
| 招聘漏斗 | 各环节转化率（投递→筛选→面试→Offer→入职），瓶颈定位 |
| 渠道效果 | 各渠道投入产出比、简历质量评分、到岗率对比 |
| 效率指标 | 平均招聘周期、各阶段停留时长、面试官响应速度 |
| 质量指标 | 试用期通过率、新人绩效分布、离职率回溯 |
| 实时仪表盘 | 可按部门/职位/时间段/招聘官多维下钻 |
| 预测分析 | 基于历史数据预测到岗时间、Offer 接受概率 |

### 3.3 关键技术选型

| 层次 | 技术选择 | 理由 |
| :--- | :--- | :--- |
| 后端框架 | Spring Boot / Go Micro | 企业级稳定性，生态成熟 |
| 流程引擎 | Camunda / Temporal | BPMN 标准，支持复杂分支/定时/补偿 |

| 消息队列 | RabbitMQ / Kafka | 异步通知、简历解析任务、事件驱动解耦 |
| 文件存储 | MinIO / OSS | 简历附件、面试录像、Offer PDF |
| AI 能力 | LLM API + 自训练 NER | 简历解析、JD 生成、智能问答、面试摘要 |
| 前端 | React/Vue + Ant Design Pro | 企业级中后台组件库，表单/表格/图表开箱即用 |
| 移动端 | UniApp / Flutter | 一套代码覆盖 H5 + 微信/飞书/钉钉小程序 |

## 4. 核心流程设计

### 4.1 招聘全流程

```
职位需求 → 审批 → 发布 → 简历收集 → 筛选 → 面试(多轮) → Offer → 背调 → 入职
   │         │       │        │         │        │          │       │       │
   ▼         ▼       ▼        ▼         ▼        ▼          ▼       ▼       ▼
编制校验   多级审批  多渠道   AI解析    自动/    评价汇总   薪酬计算  三方报告  账号开通
JD生成    预算冻结  内推激活  去重合并  人工推进  决策会议   电子签   风险标记  设备申领
                    SLA启动  人才入库  SLA监控   淘汰通知   审批流   合规存档  导师分配
```

## 5. 非功能性需求

### 5.1 性能要求

| 指标 | 目标值 |
| :--- | :--- |
| 候选人列表查询 | P99 < 200ms（万级数据量） |
| 简历解析 | 单份 < 5s，并发 50 QPS |
| 流程状态变更 | P99 < 100ms |
| 仪表盘加载 | P99 < 1s |
| 系统可用性 | 99.9%（年度停机 < 8.7h） |

### 5.2 安全与合规

- **数据加密**：候选人 PII 字段 AES-256 加密存储，传输 TLS 1.3
- **访问控制**：RBAC + 数据权限隔离（招聘官只看自己负责的职位）
- **审计日志**：所有 CRUD 操作记录操作人/时间/IP/变更前后值
- **隐私合规**：支持 GDPR/个保法，候选人可请求导出/删除个人数据
- **数据保留**：未入职候选人数据默认保留 2 年，到期自动匿名化

### 5.3 可扩展性

- **插件化渠道适配器**：新增招聘平台只需实现 `ChannelAdapter` 接口
- **流程模板市场**：支持导入/导出流程定义 JSON，跨租户复用
- **国际化**：多语言 JD、多时区面试安排、多币种薪酬
- **多租户**：SaaS 模式下数据完全隔离，共享基础设施

## 6. 集成接口清单

| 集成对象 | 协议 | 方向 | 用途 |
| :--- | :--- | :--- | :--- |
| 主流招聘平台 | REST API | 双向 | 职位发布 + 简历回收 |
| 企业 IM (飞书/钉钉/企微) | Webhook + Bot | 推送 | 面试通知、审批提醒、状态更新 |
| 日历服务 | CalDAV / Graph API | 双向 | 面试官日程同步、会议室预定 |
| 视频会议 | REST API | 单向 | 自动创建会议、获取录制回放 |
| 背调服务商 | REST API | 异步 | 发起背调 + 回调接收报告 |
| 薪酬系统 | 内部 RPC | 单向 | 获取薪级薪档、计算 Offer 方案 |
| OA 审批 | 消息队列 | 单向 | 触发审批流 + 接收审批结果 |
| 人事核心 | 事件总线 | 单向 | 入职成功后同步员工主数据 |
| AI 服务 | gRPC / REST | 单向 | 简历解析、JD 生成、智能推荐 |
