## 🎯 岗位职责

### 1. Agent 核心系统设计与开发
- 设计与实现企业级 Agent 运行时，包括任务规划、工具调用、记忆管理、反思与自我修正机制
- 构建可扩展的 Agent 编排框架，支持多 Agent 协作、Human-in-the-loop、状态持久化与断点恢复
- 深入理解 ReAct、Plan-and-Execute、Reflexion、AutoGPT 等范式，针对业务场景做架构权衡

### 2. RAG 与知识系统建设
- 设计与优化复杂 RAG 管道：文档解析、分块策略、混合检索（向量+关键词+重排序）、Query 改写
- 构建企业级知识库系统，支持权限隔离、多模态文档、增量更新、版本管理
- 攻克长上下文管理、检索质量评估、幻觉抑制等核心难题

### 3. Prompt 工程与工具生态
- 设计可维护、可测试的 Prompt 工程体系（模板化、版本化、A/B 测试）
- 抽象和标准化企业内部工具（API、数据库、文件系统），实现工具调用的自动注册与发现
- 构建工具调用沙箱，保障 Agent 执行的安全性与可审计性

### 4. 生产化与可观测性
- 解决 LLM 应用的非确定性难题：超时降级、重试策略、成本控制、调用追踪
- 构建 Agent 行为的可观测体系：全链路 Trace、决策可视化、效果评估
- 与 DevOps/MLOps 团队协作，将 Agent 系统纳入企业 CI/CD 与监控体系

### 5. 技术前瞻与团队赋能
- 跟踪国内外前沿 Agent 技术（Deep Research、Computer Use、Multi-modal Agent 等）
- 主导技术选型与架构评审，输出技术规范与最佳实践
- 指导初中级工程师，组织内部分享与代码评审
